# vulnetix_ai_governance_list (Resource)

An allow or deny list of AI tools, MCP servers, skills or clients, stored as AI Firewall guardrails: one guardrail row per pattern, of rule type <family>_<list>. The list owns its rows, so removing a pattern removes its row. The same list can be written inline as AiFirewallPolicy spec.capabilities.

Manages the `AiGovernanceList` config kind through `/config/objects/AiGovernanceList/{name}`. Applies are recorded with the provider's `manager`, so a GitOps `vulnetix config apply --prune` leaves this object alone.

Most kinds merge: an argument removed from the configuration is no longer managed, and keeps its last value on the server. A kind that is wholly declared (such as `ApiSpecSource`, `RiskStrategy` and `VexSource`) is replaced instead: a removed argument goes back to its default. Destroying the resource deletes the object.

## Example Usage

### Minimal

The arguments the kind requires, and nothing else.

```terraform
# Only the arguments the kind requires. From config-schemas examples/AiGovernanceList/minimal.yaml.

resource "vulnetix_ai_governance_list" "deny_shell_tools" {
  name     = "deny-shell-tools"
  action   = "block"
  family   = "tool"
  list     = "deny"
  patterns = ["Bash"]
}
```

### Advanced

Every argument the kind supports. A secret is a write-only `*_wo` argument fed from an ephemeral variable, so it never reaches the plan or the state; change `*_wo_version` to send a new value.

```terraform
# Every argument the kind supports. From config-schemas examples/AiGovernanceList/advanced.yaml.

resource "vulnetix_ai_governance_list" "unapproved_mcp" {
  name     = "unapproved-mcp"
  action   = "strip"
  enabled  = true
  family   = "mcp"
  list     = "deny"
  patterns = ["*-shell", "filesystem"]
  priority = 20
  labels = {
    team = "platform-security"
  }
  annotations = {
    ticket = "https://tracker.example.com/SEC-2214"
  }
}

resource "vulnetix_ai_governance_list" "approved_skills" {
  name     = "approved-skills"
  action   = "flag"
  enabled  = false
  family   = "skill"
  list     = "allow"
  patterns = ["code-review", "acme-*"]
  priority = 100
}
```

## Schema

### Required

- `action` (String) block refuses the request. flag lets it through and records the match. strip removes the matched tool or MCP server and sends the rest of the request; it applies to the tool and mcp families only, because a skill is a value inside another tool and a client is a header. One of `block`, `flag`, `strip`.
- `family` (String) tool: a tool offered to the model. mcp: an MCP server wired into the session. skill: an agent skill. client: the calling client, named by its headers (claude-code, codex-cli). One of `tool`, `mcp`, `skill`, `client`.
- `list` (String) One of `allow`, `deny`.
- `name` (String) The object's name (`metadata.name`), unique per kind within the tenant. Changing it replaces the object.
- `patterns` (Set of String)

- `priority` (Number) Evaluation order among guardrails, lowest first. Schema default: `100`.
