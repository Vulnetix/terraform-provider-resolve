# vulnetix_ai_provider (Resource)

A custom AI Firewall provider owned by the tenant: a model server the gateway forwards to, beside the built-in catalogue. Only this tenant sees or uses it. metadata.name is the provider slug, which becomes the gateway path prefix (/<slug>/<org>/v1/...) and is what AiFirewallPolicy providers and models refer to. A tenant has at most 10 custom providers, and a slug that a built-in provider uses is refused at apply.

Manages the `AiProvider` config kind through `/config/objects/AiProvider/{name}`. Applies are recorded with the provider's `manager`, so a GitOps `vulnetix config apply --prune` leaves this object alone.

Most kinds merge: an argument removed from the configuration is no longer managed, and keeps its last value on the server. A kind that is wholly declared (most of them, such as `ApiSpecSource`, `RiskStrategy` and `VexSource`) is replaced instead: a removed argument goes back to its default. Destroying the resource deletes the object, or lets go of it for a kind the server never deletes (such as `Organization`). Some kinds wait on a person after they are applied (an invited `Member`, a Slack connection): `status.phase` says so, and Terraform does not wait.

## Example Usage

### Minimal

The arguments the kind requires, and nothing else.

```terraform
# Only the arguments the kind requires. From config-schemas examples/AiProvider/minimal.yaml.

resource "vulnetix_ai_provider" "acme_vllm" {
  name     = "acme-vllm"
  auth     = "bearer"
  base_url = "https://llm.acme.example"
  protocol = "openai-chat"
}
```

### Advanced

Every argument the kind supports. A secret is a write-only `*_wo` argument fed from an ephemeral variable, so it never reaches the plan or the state; change `*_wo_version` to send a new value.

```terraform
# Every argument the kind supports. From config-schemas examples/AiProvider/advanced.yaml.

variable "acme_vllm_api_key" {
  type      = string
  sensitive = true
  ephemeral = true
}
variable "acme_ollama_api_key" {
  type      = string
  sensitive = true
  ephemeral = true
}

resource "vulnetix_ai_provider" "acme_vllm" {
  name               = "acme-vllm"
  api_key_wo         = var.acme_vllm_api_key
  api_key_wo_version = 1
  auth               = "bearer"
  base_url           = "https://llm.acme.example"
  display_name       = "ACME vLLM cluster"
  models = [
    {
      context_window = 262144
      id             = "qwen3-coder-30b"
      images         = false
      max_tokens     = 65536
      name           = "Qwen3 Coder 30B"
    },
    {
      context_window = 131072
      id             = "qwen2.5-vl-72b"
      images         = true
      max_tokens     = 8192
      name           = "Qwen2.5 VL 72B"
    },
  ]
  protocol    = "openai-responses"
  server_kind = "openai-compatible"
  labels = {
    team = "ml-platform"
  }
  annotations = {
    runbook = "https://wiki.example.com/ml-platform/vllm"
  }
}

resource "vulnetix_ai_provider" "acme_ollama" {
  name               = "acme-ollama"
  api_key_wo         = var.acme_ollama_api_key
  api_key_wo_version = 1
  auth               = "x-api-key"
  base_url           = "https://ollama.acme.example:11434"
  display_name       = "ACME Ollama"
  models = [
    {
      context_window = 131072
      id             = "llama3.1:70b"
      max_tokens     = 0
      name           = "Llama 3.1 70B"
    },
  ]
  protocol    = "openai-chat"
  server_kind = "ollama"
}
```

## Schema

### Required

- `auth` (String) How the API key is sent. bearer: Authorization: Bearer <key>. x-api-key: an x-api-key header, plus anthropic-version for anthropic-messages. cf-aig: a cf-aig-authorization header, for Cloudflare AI Gateway. One of `bearer`, `x-api-key`, `cf-aig`.
- `base_url` (String) https://host[:port] and nothing more: no path, query or fragment. The gateway adds the protocol's own path. The host must be publicly reachable; private, loopback and link-local addresses are refused at apply, and again at every connection.
- `name` (String) The object's name (`metadata.name`), unique per kind within the tenant. Changing it replaces the object.
- `protocol` (String) The request surface the server speaks: openai-chat (Chat Completions), openai-responses (Responses, which Codex needs) or anthropic-messages (Messages, which Claude Code speaks). The gateway refuses requests on any other surface. One of `openai-chat`, `openai-responses`, `anthropic-messages`.

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `annotations` (Map of String) Free key/value notes for people and tools (`metadata.annotations`), such as a ticket link.
- `api_key_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) Where the client reads the API key. It is stored encrypted for this tenant and provider, and is never exported or shown in a plan. Left out, the key on the server is kept; with no key at all, the gateway refuses requests with provider_key_missing. Write-only: never stored in state. Needs Terraform 1.11 or later. Change `api_key_wo_version` to send a new value.
- `api_key_wo_version` (Number) Any number. Change it to send `api_key_wo` again; Terraform cannot see a write-only value change.
- `display_name` (String) The label the console shows. Defaults to the slug.
- `labels` (Map of String) Free key/value labels (`metadata.labels`). Stored with the object, never interpreted by the server.
- `models` (Attributes Set) The models the server offers. (see [below for nested schema](#nestedatt--models))
- `server_kind` (String) The server type. ollama and llama-server speak openai-chat only. One of `openai-compatible`, `ollama`, `llama-server`. Schema default: `openai-compatible`.

### Nested Schema for `status`

Read-Only:

- `authorization_url` (String) Where a person authorizes the object while the phase is `AwaitingAuthorization`.
- `extra` (Map of String) Other fields the kind reports, such as an invitation's expiry or a service account's principal. Structured values are JSON.
- `message` (String) Why the object is in its phase, when the server says.
- `object_uuid` (String) The object's id on the server.
- `once` (Map of String, Sensitive) Credentials the server shows only when it creates the object: a service account's `apiKey` and `secret`, a messaging connection's `signingSecret`, a log source's ingest token. They are kept in the state from the create, so keep the state encrypted. They cannot be read again: replace the object to get new ones.
- `phase` (String) `Applied` for most objects. `Pending` when the object waits on someone (an invited member who has not accepted), `AwaitingAuthorization` when a person has to authorize it in a browser at `authorization_url`. Terraform does not wait for either. `Unmanaged` means the object exists but no manager owns it.
