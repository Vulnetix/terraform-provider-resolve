# vulnetix_api_spec_source (Resource)

Where Vulnetix finds an organisation's OpenAPI and Swagger descriptions. Each source is one place to read specs from: a file in a repository, a URL, a host to probe for well-known paths, or a connected API gateway or catalogue. A tenant may declare many, each named.

Manages the `ApiSpecSource` config kind through `/config/objects/ApiSpecSource/{name}`. Applies are recorded with the provider's `manager`, so a GitOps `vulnetix config apply --prune` leaves this object alone.

Most kinds merge: an argument removed from the configuration is no longer managed, and keeps its last value on the server. A kind that is wholly declared (such as `ApiSpecSource`, `RiskStrategy` and `VexSource`) is replaced instead: a removed argument goes back to its default. Destroying the resource deletes the object.

## Example Usage

### Minimal

The arguments the kind requires, and nothing else.

```terraform
# Only the arguments the kind requires. From config-schemas examples/ApiSpecSource/minimal.yaml.

resource "vulnetix_api_spec_source" "payments_openapi" {
  name = "payments-openapi"
  source = {
    url = {
      url = "https://api.acme.com/openapi.json"
    }
  }
}
```

### Advanced

Every argument the kind supports. A secret is a write-only `*_wo` argument fed from an ephemeral variable, so it never reaches the plan or the state; change `*_wo_version` to send a new value.

```terraform
# Every argument the kind supports. From config-schemas examples/ApiSpecSource/advanced.yaml.

resource "vulnetix_api_spec_source" "payments_openapi" {
  name     = "payments-openapi"
  owner    = "payments-team"
  schedule = "daily"
  source = {
    repo = {
      path       = "api/openapi.yaml"
      repository = "acme/payments"
    }
  }
  tags = ["payments", "public"]
  labels = {
    team = "payments"
  }
  annotations = {
    ticket = "https://tracker.example.com/API-311"
  }
}

resource "vulnetix_api_spec_source" "public_api_spec" {
  name = "public-api-spec"
  probe = {
    mode = "exact"
  }
  schedule = "hourly"
  source = {
    url = {
      url = "https://api.acme.com/openapi.json"
    }
  }
}

resource "vulnetix_api_spec_source" "staging_host" {
  name = "staging-host"
  probe = {
    authorize = true
    mode      = "authorized"
  }
  schedule = "weekly"
  source = {
    host = {
      host = "staging.acme.com:8443"
    }
  }
}

resource "vulnetix_api_spec_source" "edge_gateway" {
  name     = "edge-gateway"
  owner    = "platform-team"
  schedule = "6h"
  source = {
    connector = {
      kind = "aws_apigw"
      ref  = "a1b2c3d4e5"
    }
  }
  tags = ["edge"]
}
```

- `probe` (Attributes) How a url or host source is reached. owned probes well-known paths once an ownership proof is verified; authorized probes after the organisation asserts it is allowed to test the host; exact fetches only the given url and never guesses a path. - `tags` (List of String) Free labels applied to every spec this source finds.
