# vulnetix_factory_budget (Resource)

A Software Factory budget: a limit on the tokens or calls the factory spends, for the whole factory, one GitHub organisation, one repository, one workflow or one step, with alerts and an action at the limit. metadata.name is the budget's name in the console. One budget per scope and provider. The Factory budget (the whole factory, per month, every provider) is set with the budget settings of FactorySettings, not here. Removing the document deletes the budget; its ledger is kept.

An object of this kind can reference `FactoryWorkflow` objects. Reference those resources' attributes, or add `depends_on`, so Terraform applies them first.

Manages the `FactoryBudget` config kind through `/config/objects/FactoryBudget/{name}`. Applies are recorded with the provider's `manager`, so a GitOps `vulnetix config apply --prune` leaves this object alone.

Most kinds merge: an argument removed from the configuration is no longer managed, and keeps its last value on the server. A kind that is wholly declared (most of them, such as `ApiSpecSource`, `RiskStrategy` and `VexSource`) is replaced instead: a removed argument goes back to its default. Destroying the resource deletes the object, or lets go of it for a kind the server never deletes (such as `Organization`). Some kinds wait on a person after they are applied (an invited `Member`, a Slack connection): `status.phase` says so, and Terraform does not wait.

## Example Usage

### Minimal

The arguments the kind requires, and nothing else.

```terraform
# Only the arguments the kind requires. From config-schemas examples/FactoryBudget/minimal.yaml.

resource "vulnetix_factory_budget" "org_monthly_tokens" {
  name       = "org-monthly-tokens"
  applies_to = "org"
  limit      = 20000000
}
```

### Advanced

Every argument the kind supports. A secret is a write-only `*_wo` argument fed from an ephemeral variable, so it never reaches the plan or the state; change `*_wo_version` to send a new value.

```terraform
# Every argument the kind supports. From config-schemas examples/FactoryBudget/advanced.yaml.

resource "vulnetix_factory_budget" "patch_train_daily" {
  name            = "patch-train-daily"
  action_at_limit = "pause_run"
  alert_at        = [50, 80, 100]
  applies_to      = "workflow"
  limit           = 1500000
  model_providers = "anthropic,openai"
  unit            = "tokens"
  window          = "day"
  workflow        = "security-patch-train"
  labels = {
    team = "appsec"
  }
}

resource "vulnetix_factory_budget" "patch_step" {
  name            = "patch-step"
  action_at_limit = "downgrade_to_fast"
  applies_to      = "node"
  limit           = 300000
  node            = "patch"
  window          = "node"
  workflow        = "security-patch-train"
}

resource "vulnetix_factory_budget" "payments_repo" {
  name            = "payments-repo"
  action_at_limit = "escalate_human"
  applies_to      = "repo"
  limit           = 5000
  repository      = "acme/payments"
  unit            = "calls"
  window          = "month"
}

resource "vulnetix_factory_budget" "acme_org" {
  name            = "acme-org"
  action_at_limit = "alert_only"
  applies_to      = "org"
  installation_id = 41234567
  limit           = 10000000
}
```

## Schema

### Required

- `applies_to` (String) What the budget limits. tenant: the whole factory. org: the repositories of one GitHub App installation, or every organisation when installationId is left out. repo: one repository. workflow: one workflow. node: one step of one workflow. One of `tenant`, `org`, `repo`, `workflow`, `node`.
- `limit` (Number) The limit, in unit, for the window. Not above the budget it sits inside: a step's budget not above its workflow's monthly budget, and any other not above the Factory budget, in the same unit.
- `name` (String) The object's name (`metadata.name`), unique per kind within the tenant. Changing it replaces the object.

### Optional

- `action_at_limit` (String) What the factory does when the limit is reached: pause the run, downgrade to the fast model, switch to the Pix allocation, ask a person, stop hard, or only alert. Defaults to alert_only. One of `alert_only`, `pause_run`, `downgrade_to_fast`, `switch_to_pix_allocation`, `escalate_human`, `hard_stop`. Schema default: `alert_only`.
- `alert_at` (Set of Number) The percentages of the limit, ascending, from 1 to 100, at which the factory raises an alert. Defaults to 80 and 100.
- `annotations` (Map of String) Free key/value notes for people and tools (`metadata.annotations`), such as a ticket link.
- `installation_id` (Number) org: the GitHub App installation id of the organisation.
- `labels` (Map of String) Free key/value labels (`metadata.labels`). Stored with the object, never interpreted by the server.
- `model_providers` (String) The model providers the budget counts, as one provider id or a comma-separated list, such as anthropic or pix,openai. Every provider when left out.
- `node` (String) node: the id of the step in the workflow's graph.
- `repository` (String) repo: the repository, owner/name.
- `unit` (String) What the limit counts: model tokens, or calls. Defaults to tokens. One of `tokens`, `calls`. Schema default: `tokens`.
- `window` (String) The period the limit covers: one run, a day, a week (from Monday) or a calendar month, all in UTC, or one step's run (node). tenant and workflow take run, day, week or month; org and repo take month; node takes node. Defaults to month, and to node for a node budget. One of `run`, `day`, `week`, `month`, `node`.
- `workflow` (String) workflow and node: the metadata.name of a FactoryWorkflow.

### Read-Only

- `id` (String) The object's name, the same as `name`.
- `status` (Attributes) What the server says about the object beyond its spec. (see [below for nested schema](#nestedatt--status))

### Nested Schema for `status`

Read-Only:

- `authorization_url` (String) Where a person authorizes the object while the phase is `AwaitingAuthorization`.
- `extra` (Map of String) Other fields the kind reports, such as an invitation's expiry or a service account's principal. Structured values are JSON.
- `message` (String) Why the object is in its phase, when the server says.
- `object_uuid` (String) The object's id on the server.
- `once` (Map of String, Sensitive) Credentials the server shows only when it creates the object: a service account's `apiKey` and `secret`, a messaging connection's `signingSecret`, a log source's ingest token. They are kept in the state from the create, so keep the state encrypted. They cannot be read again: replace the object to get new ones.
- `phase` (String) `Applied` for most objects. `Pending` when the object waits on someone (an invited member who has not accepted), `AwaitingAuthorization` when a person has to authorize it in a browser at `authorization_url`. Terraform does not wait for either. `Unmanaged` means the object exists but no manager owns it.
