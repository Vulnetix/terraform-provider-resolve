# vulnetix_package_firewall_policy (Resource)

The tenant's package firewall policy: what the registry proxy refuses to serve, the posture it enforces in, per-ecosystem posture overrides, and the upstream mirrors it fetches from. One per tenant. The allow and deny lists are PackageList objects. A field left out keeps its current value.

Manages the `PackageFirewallPolicy` config kind through `/config/objects/PackageFirewallPolicy/{name}`. Applies are recorded with the provider's `manager`, so a GitOps `vulnetix config apply --prune` leaves this object alone.

Most kinds merge: an argument removed from the configuration is no longer managed, and keeps its last value on the server. A kind that is wholly declared (such as `ApiSpecSource`, `RiskStrategy` and `VexSource`) is replaced instead: a removed argument goes back to its default. Destroying the resource deletes the object.

## Example Usage

### Minimal

The arguments the kind requires, and nothing else.

```terraform
# Only the arguments the kind requires. From config-schemas examples/PackageFirewallPolicy/minimal.yaml.

resource "vulnetix_package_firewall_policy" "default" {
}
```

### Advanced

Every argument the kind supports. A secret is a write-only `*_wo` argument fed from an ephemeral variable, so it never reaches the plan or the state; change `*_wo_version` to send a new value.

```terraform
# Every argument the kind supports. From config-schemas examples/PackageFirewallPolicy/advanced.yaml.

resource "vulnetix_package_firewall_policy" "default" {
  block = {
    active     = true
    bad_actors = true
    eol        = true
    kev        = true
    malware    = true
    poc        = false
    weaponized = true
  }
  cooldown_days = 3
  ecosystems = {
    go = {
      mode = "warn"
    }
    npm = {
      mode = "allowlist_only"
    }
    pypi = {
      mode = "enforce"
    }
  }
  mirrors = [
    {
      active    = true
      ecosystem = "go"
      priority  = 0
      url       = "https://proxy.golang.org"
    },
    {
      active    = false
      ecosystem = "go"
      priority  = 1
      url       = "https://goproxy.io"
    },
    {
      ecosystem = "npm"
      priority  = 0
      url       = "https://registry.npmjs.org"
    },
    {
      ecosystem = "pypi"
      priority  = 0
      url       = "https://pypi.org/simple"
    },
  ]
  mode = "enforce"
  review = {
    stale_decision_days = 180
    stale_usage_days    = 60
  }
  thresholds = {
    cess = 8
    cvss = 9
    epss = 0.5
  }
  version_lag = 10
  labels = {
    team = "platform-security"
  }
  annotations = {
    ticket = "https://jira.example.com/browse/SEC-2210"
  }
}
```

## Schema

### Optional

- `annotations` (Map of String) Free key/value notes for people and tools (`metadata.annotations`), such as a ticket link.
- `block` (Attributes) Signals that block a version on their own. All default to false. (see [below for nested schema](#nestedatt--block))
- `cooldown_days` (Number) Block a version published fewer than this many days ago. 0 turns it off. Schema default: `0`.
- `ecosystems` (Attributes Map) Per-ecosystem posture, keyed by ecosystem, overriding mode. An ecosystem left out inherits mode. (see [below for nested schema](#nestedatt--ecosystems))
- `labels` (Map of String) Free key/value labels (`metadata.labels`). Stored with the object, never interpreted by the server.
- `mirrors` (Attributes Set) The upstream registries the proxy fetches from. When set, this is the whole list: mirrors not named are removed. (see [below for nested schema](#nestedatt--mirrors))
- `mode` (String) The tenant's default posture. enforce blocks what the policy says to block. warn only observes: every block becomes an advisory logged as WARN, except a deny-list hit, which always blocks. allowlist_only refuses any package without an allow entry. One of `enforce`, `warn`, `allowlist_only`. Schema default: `enforce`.
- `name` (String) The object's name. PackageFirewallPolicy is one per tenant, so it is always `default`.
- `review` (Attributes) When the console flags a curation decision for review. Read by the console only, never by the proxy. (see [below for nested schema](#nestedatt--review))
- `thresholds` (Attributes) Block a version with a vulnerability scoring at or above a threshold. 0 turns that threshold off. (see [below for nested schema](#nestedatt--thresholds))
- `version_lag` (Number) Block a version more than this many releases behind its package's newest release (rank 0 is the newest, so 2 serves the three newest). 0 turns it off. Enforced only for ecosystems whose proxy can list every version, and not in warn mode. Note that this is the opposite of the QualityGate versionLag check. Schema default: `0`.
