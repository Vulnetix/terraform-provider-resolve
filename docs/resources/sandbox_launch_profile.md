# vulnetix_sandbox_launch_profile (Resource)

The launch configuration of one Pix sandbox: what the next launch or relaunch of the sandbox installs and how Belai runs on it. A field left out inherits the product default. The sandbox is bought in the console and never created here; one sandbox has one launch configuration, so a document for a sandbox adopts it. Applying a change marks the sandbox for relaunch. The egress mode is SandboxEgressPolicy's; model providers, provisioning and models keep their own console pages. Only an owner or admin can change it. Deleting the document resets every field it manages to inherit.

Manages the `SandboxLaunchProfile` config kind through `/config/objects/SandboxLaunchProfile/{name}`. Applies are recorded with the provider's `manager`, so a GitOps `vulnetix config apply --prune` leaves this object alone.

Most kinds merge: an argument removed from the configuration is no longer managed, and keeps its last value on the server. A kind that is wholly declared (most of them, such as `ApiSpecSource`, `RiskStrategy` and `VexSource`) is replaced instead: a removed argument goes back to its default. Destroying the resource deletes the object, or lets go of it for a kind the server never deletes (such as `Organization`). Some kinds wait on a person after they are applied (an invited `Member`, a Slack connection): `status.phase` says so, and Terraform does not wait.

## Example Usage

### Minimal

The arguments the kind requires, and nothing else.

```terraform
# Only the arguments the kind requires. From config-schemas examples/SandboxLaunchProfile/minimal.yaml.

resource "vulnetix_sandbox_launch_profile" "dev_sandbox" {
  name    = "dev-sandbox"
  sandbox = "3c9e1f2a-7b4d-4e6f-8a1b-2c3d4e5f6a7b"
}
```

### Advanced

Every argument the kind supports. A secret is a write-only `*_wo` argument fed from an ephemeral variable, so it never reaches the plan or the state; change `*_wo_version` to send a new value.

```terraform
# Every argument the kind supports. From config-schemas examples/SandboxLaunchProfile/advanced.yaml.

resource "vulnetix_sandbox_launch_profile" "dev_sandbox" {
  name       = "dev-sandbox"
  classifier = "jev"
  extensions = [
    {
      checksum = "sha256-AbCdEf0123456789AbCdEf0123456789AbCdEf01234="
      name     = "ripgrep"
      registry = "nixpkgs"
      version  = "14.1.0"
    },
  ]
  image   = "ghcr.io/vulnetix/pix-sandbox@sha256:2f4c6a8e0b1d3f5a7c9e1b3d5f7a9c1e3b5d7f9a1c3e5b7d9f1a3c5e7b9d1f3a"
  notes   = "Pinned to the October image until the Python 3.13 packs land."
  packs   = ["python", "node"]
  sandbox = "3c9e1f2a-7b4d-4e6f-8a1b-2c3d4e5f6a7b"
  version_policy = {
    pins = {
      ruff = "0.8.4"
    }
    strategy = "pinned"
  }
  web_controls         = true
  web_guardrails_off   = false
  web_project_settings = true
  labels = {
    team = "platform"
  }
}
```

## Schema

### Required

- `name` (String) The object's name (`metadata.name`), unique per kind within the tenant. Changing it replaces the object.
- `sandbox` (String) The sandbox, by its id (a lower-case UUID), as the console's sandbox page shows it.

### Optional

- `annotations` (Map of String) Free key/value notes for people and tools (`metadata.annotations`), such as a ticket link.
- `classifier` (String) The decision model Belai uses: clef, jev, or tev1 (used only while the sandbox's provider keys include Together AI). One of `clef`, `jev`, `tev1`.
- `extensions` (Attributes List) Extra packages installed, at most 64. (see [below for nested schema](#nestedatt--extensions))
- `image` (String) The machine image, pinned by digest (registry/name@sha256:<64 hex>), never a tag. Left out, the product default image.
- `labels` (Map of String) Free key/value labels (`metadata.labels`). Stored with the object, never interpreted by the server.
- `notes` (String) Free notes for the sandbox's owners, one line of at most 2000 characters.
- `packs` (Set of String) The tool packs installed, at most 32. An empty list installs none; left out, the product default packs.
- `version_policy` (Attributes) Which versions of installed packages a launch aims at. Left out, none is set. (see [below for nested schema](#nestedatt--version_policy))
- `web_controls` (Boolean) Let a browser session control Belai (belai rc --web-controls).
- `web_guardrails_off` (Boolean) Let a browser session turn the guardrails off. Needs webControls on.
- `web_project_settings` (Boolean) Let a browser session change project settings.

### Read-Only

- `id` (String) The object's name, the same as `name`.
- `status` (Attributes) What the server says about the object beyond its spec. (see [below for nested schema](#nestedatt--status))

### Nested Schema for `extensions`

Required:

- `name` (String) The package name in its registry.

Optional:

- `checksum` (String) The expected content hash, as the registry states it (sha256-...).
- `registry` (String) Where the package comes from. Left out, nixpkgs. One of `nixpkgs`, `nixhub`, `flakehub`.
- `version` (String) The version wanted. Left out, the registry's current one.

### Nested Schema for `version_policy`

Required:

- `strategy` (String) One of `safest`, `stable`, `latest`, `rolling`, `pinned`.

Optional:

- `pins` (Map of String) Versions pinned by nixpkgs attribute, at most 100. The pinned strategy needs at least one.


<a id="nestedatt--status"></a>
### Nested Schema for `status`

Read-Only:

- `authorization_url` (String) Where a person authorizes the object while the phase is `AwaitingAuthorization`.
- `extra` (Map of String) Other fields the kind reports, such as an invitation's expiry or a service account's principal. Structured values are JSON.
- `message` (String) Why the object is in its phase, when the server says.
- `object_uuid` (String) The object's id on the server.
- `once` (Map of String, Sensitive) Credentials the server shows only when it creates the object: a service account's `apiKey` and `secret`, a messaging connection's `signingSecret`, a log source's ingest token. They are kept in the state from the create, so keep the state encrypted. They cannot be read again: replace the object to get new ones.
- `phase` (String) `Applied` for most objects. `Pending` when the object waits on someone (an invited member who has not accepted), `AwaitingAuthorization` when a person has to authorize it in a browser at `authorization_url`. Terraform does not wait for either. `Unmanaged` means the object exists but no manager owns it.
